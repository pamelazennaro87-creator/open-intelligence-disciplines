# Visuals

This folder will contain diagrams, matrices and process maps that support the discipline profiles and comparisons.

## Planned Content

- Discipline relationship matrix
- Collection-to-analysis process maps
- Confidence and source evaluation frameworks
- Side-by-side comparison tables (rendered as diagrams where useful)

## Standards

- Prefer clarity over decoration
- Every visual should be understandable from the accompanying text
- Source data for any quantitative visual must be documented
